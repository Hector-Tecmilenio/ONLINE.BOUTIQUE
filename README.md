microservices-demo-devops-project

**Proyecto DevOps - Demostración de Microservicios**



Este repositorio es una adaptación personal del proyecto GoogleCloudPlatform/microservices-demo

también conocido como Online Boutique, una aplicación de código abierto 
basada en arquitectura de microservicios y desplegada en la nube.



**Descripción General del Proyecto**



Este trabajo forma parte del Proyecto Integrador de la materia de DevOps, cuyo propósito es modificar y configurar la aplicación Online Boutique para funcionar con una versión diferente de Terraform y adaptarla a un entorno de infraestructura alternativo fuera de Google Cloud.



**Objetivos del Proyecto**



Ajustar la infraestructura para una versión personalizada de Terraform.



Implementar Ansible para la automatización y gestión de configuraciones.



Desplegar los servicios utilizando Kubernetes y Docker.



Configurar un flujo de integración y entrega continua (CI/CD) con GitHub Actions.



Aplicar buenas prácticas DevOps en un entorno de microservicios.



**Tecnologías y Herramientas Utilizadas**



Lenguajes: Go, Python, Java, Node.js, C#



Infraestructura: Kubernetes, Docker, Terraform, Ansible



Herramientas DevOps: GitHub Actions, Prometheus, Grafana



Control de Versiones: Git y GitHub



Estrategia de Ramas (GitFlow)



**Metodología** 



main → Código estable listo para producción



**Adaptación Realizada**



A diferencia del proyecto original que se ejecuta en Google Cloud, esta versión fue modificada para ser compatible con una versión diferente de Terraform y poder desplegarse en infraestructuras distintas, manteniendo la misma estructura de microservicios.
